# schizocardium_single-cell
Code for analysis and figures from _[Distinct cell states define larval and adult body plans in a hemichordate_, Bump et al., 2026](https://doi.org/10.1038/s41467-026-77191-y)
[![DOI](https://zenodo.org/badge/1265274919.svg)](https://doi.org/10.5281/zenodo.21799035)

Raw sequencing data is available through NBCI: BioProject [PRJNA1297089](https://www.ncbi.nlm.nih.gov/bioproject/?term=PRJNA1297089)

Bump P, Brewster C, Formery L, Lubeck L, Campbell C, Morri M, Sit R, Rokhsar DS, Benham-Pyle B, Alvarado AS, Lowe CJ. Distinct cell states define larval and adult body plans in a hemichordate. Nat Commun. 2026 Sep 8;17(1):9358. doi: 10.1038/s41467-026-77191-y. PMID: 42711331; PMCID: PMC13554239.
